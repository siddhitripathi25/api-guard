# express-api-guard

Security and protection middleware toolkit for Express.js.

`express-api-guard` provides simple, reusable middleware to add common API security protections to Express applications.

## Features

- 🔐 Request ID generation
- 🚦 Rate limiting
- 🛡️ Security headers
- 🚫 IP blocking and allowlisting
- 📦 Request size limiting
- 📝 Security event logging

## Installation

```bash
npm install express-api-guard
